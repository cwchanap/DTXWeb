# Jest DOM v7 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade all workspace users of `@testing-library/jest-dom` to v7 while declaring its required DOM peer explicitly and preserving a reproducible Bun lockfile.

**Architecture:** Keep the dependency local to each package that imports the matcher setup. Update the three package manifests together, regenerate the root Bun lockfile once, and rely on existing package tests plus workspace lint/type checks for compatibility verification.

**Tech Stack:** Bun workspaces, Vitest, Testing Library, Svelte 5, TypeScript.

## Global Constraints

- Node.js remains `>=22.0.0`.
- Use `@testing-library/jest-dom` `^7.0.0`.
- Use `@testing-library/dom` `^10.4.1`, satisfying the v7 peer range `>=10 <11`.
- Do not change production dependencies or test behaviour.
