# Rust 1.88 Desktop Dependency Stack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Raise the desktop Rust toolchain to 1.88 and land the six related dependency updates as one reproducible, fully verified change.

**Architecture:** Pin the repository toolchain and every desktop Rust workflow to Rust 1.88, update direct Cargo constraints, then let Cargo resolve the transitive `quinn-proto` and `serde_with` updates in the same lockfile. Regenerate ts-rs native bindings and verify formatting, clippy, default tests, E2E-feature tests, desktop E2E, and cross-platform builds through CI.

**Tech Stack:** Rust 1.88, Cargo, Tauri 2, ts-rs, rusqlite, GitHub Actions, Bun.

## Global Constraints

- Set `rust-version = "1.88"`.
- Pin `rust-toolchain.toml` to `1.88.0`.
- Use `base64` `0.23`.
- Use `rusqlite` `0.40` with the existing `bundled` feature.
- Use `ts-rs` `12.0`.
- Pin `time` exactly to `0.3.47`.
- Resolve `quinn-proto` to `0.11.16` and `serde_with` to `3.17.0` in `Cargo.lock`.
- Keep all existing Tauri features and platform-specific dependencies unchanged.
