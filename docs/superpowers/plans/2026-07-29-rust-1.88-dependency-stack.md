# Rust 1.95 Desktop Dependency Stack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Raise the desktop Rust toolchain to 1.95 and land the six related dependency updates as one reproducible, fully verified change.

**Architecture:** Pin the repository toolchain and every desktop Rust workflow to Rust 1.95, update direct Cargo constraints, then resolve only manifest-required changes plus the reviewed transitive `quinn-proto` and `serde_with` updates in the same lockfile. Rust 1.95 is required because `libsqlite3-sys 0.38.1`, pulled by `rusqlite 0.40.1`, uses the built-in `cfg_select!` macro stabilised in Rust 1.95. Regenerate ts-rs native bindings and verify formatting, clippy, default tests, E2E-feature tests, desktop E2E, and cross-platform builds through CI.

**Tech Stack:** Rust 1.95, Cargo, Tauri 2, ts-rs, rusqlite, GitHub Actions, Bun.

## Global Constraints

- Set `rust-version = "1.95"`.
- Pin `rust-toolchain.toml` to `1.95.0`.
- Use `base64` `0.23`.
- Use `rusqlite` `0.40` with the existing `bundled` feature.
- Use `ts-rs` `12.0`.
- Pin `time` exactly to `0.3.47`.
- Resolve `quinn-proto` to `0.11.16` and `serde_with` to `3.21.0` in `Cargo.lock`.
- Keep `base64 0.22` transitively where required by pinned `reqwest 0.12.15`.
- Keep all existing Tauri features and platform-specific dependencies unchanged.
